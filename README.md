# Folio — Markdown Viewer

Electron + Reactで作った、シンプルなMarkdownビューアーです。

異なるフォルダーにあるMarkdownファイルを、移動やコピーをせずにひとつのサイドバーで管理できます。レンダリングされたプレビューと、元のMarkdownテキストを切り替えて読むことができます。

## 主な機能

- **ファイル単位のライブラリ**：`.md` / `.markdown` を複数選択して追加。別フォルダーの同名ファイルもフルパスで区別します。
- **Markdownプレビュー**：表、チェックリスト、取り消し線、リンク、画像に対応します。
- **コードのシンタックスハイライト**：言語指定のあるコードブロックを色分けし、コピーボタンを表示します。
- **数式表示**：KaTeXでインライン数式・ブロック数式を表示します。
- **Raw表示**：元のテキストを読み取り専用の等幅フォントで表示し、選択・コピーできます。
- **表示のカスタマイズ**：ライト・ダーク・セピアの3テーマ、ゴシック・明朝・等幅フォント、13〜24 pxの文字サイズを選択できます。
- **読むための操作**：ファイル名・パスの検索、目次からの移動、サイドバーの開閉、ファイルの再読み込みに対応します。
- **起動時の復元**：ファイル一覧、選択ファイル、テーマ、フォント、文字サイズを保存します。
- **macOSとの連携**：Finderの「このアプリケーションで開く」やDockアイコンへのファイルドロップに対応します。

## 必要な環境

- Node.js **22.12以上**とnpm
- macOSアプリのビルドにはmacOSが必要です。
- 初回の依存パッケージやElectron本体の取得にはインターネット接続が必要です。

## クイックスタート

```sh
git clone https://github.com/yenshan/md_viewer.git
cd md_viewer
./start.sh
```

`start.sh` は、必要な依存パッケージがなければインストールし、フロントエンドをビルドしてElectronを起動します。別のディレクトリーからスクリプトの絶対パスで実行することもできます。

開発モードで起動する場合：

```sh
npm ci
npm run dev
```

## 使い方

1. 左上の「ファイルを追加」、または `⌘O`（macOS）/ `Ctrl+O` でMarkdownファイルを選択します。
2. 別のフォルダーのファイルを追加する場合は、同じ操作を繰り返します。
3. 左サイドバーで読むファイルを選択します。検索欄ではファイル名とパスで絞り込めます。
4. 上部の「プレビュー」「Raw」で表示を切り替えます。
5. 「表示設定」からテーマ、フォント、文字サイズを変更します。

一覧の **×** はファイルをライブラリから外す操作です。元ファイルは削除しません。

外部エディターで内容を変更したら、上部の再読み込みボタンを押してください。自動監視・編集・保存には対応していません。目次はプレビュー表示で使用できます。

## macOSアプリのビルド

```sh
./build-mac.sh
```

依存パッケージの準備、フロントエンドのビルド、`.app` の作成を行います。引数を省略すると、実行中のNode.jsと同じアーキテクチャーでビルドします。

| 対象 | コマンド | 出力先 |
| --- | --- | --- |
| Apple Silicon | `./build-mac.sh --arm64` | `release/mac-arm64/Folio.app` |
| Intel | `./build-mac.sh --x64` | `release/mac/Folio.app` |
| 両対応（Universal） | `./build-mac.sh --universal` | `release/mac-universal/Folio.app` |

生成した `Folio.app` をアプリケーションフォルダーにコピーし、Finderから起動してください。Node.jsやプロジェクトのソースは、生成したアプリの実行には不要です。

このスクリプトはローカル利用向けのアドホック署名を使用します。AppleのDeveloper IDによる署名・公証は行いません。配布用の署名・公証は別途設定が必要です。

### Finderの「このアプリケーションで開く」

1. 新しくビルドした `Folio.app` をアプリケーションフォルダーにコピーし、一度起動します。
2. Finderで `.md` / `.markdown` ファイルを右クリックします。
3. 「このアプリケーションで開く」→「Folio」を選択します。

候補に表示されない場合は「その他…」から `Folio.app` を選択してください。

未起動ならアプリを起動してファイルを表示し、起動済みなら既存ウィンドウのライブラリに追加して表示します。複数ファイルや、ウィンドウを閉じた状態からの読み込みにも対応します。既定のアプリは自動変更しません。

### インストーラー

```sh
npm ci
npm run dist
```

実行したOSに応じて、macOSはDMG、WindowsはNSIS、LinuxはAppImageを `release/` に出力する設定です。各OS上でのビルドを推奨します。Windows・Linuxでのビルドや動作は未検証です。

## Markdownの書き方

### 表とチェックリスト

```markdown
| 項目 | 状態 |
| --- | --- |
| Markdownの表示 | 対応 |
| 数式の表示 | 対応 |

- [x] ファイルを追加する
- [ ] 読み進める
```

表の列幅は内容に応じて調整し、横長の表は横スクロールできます。

### コードブロック

コードフェンスの後ろに言語名を指定します。

````markdown
```javascript
const message = 'Hello, Folio!';
console.log(message);
```
````

### 数式

インライン数式は `$...$`、ブロック数式は `$$...$$` で囲みます。

```markdown
エネルギーは $E = mc^2$ で表せます。

$$
\int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}
$$
```

### 画像とリンク

- ローカル画像は、Markdownと同じフォルダーまたはその配下の **PNG / JPEG / GIF / WebP / AVIF** に対応します。
- 外部HTTPS画像の表示にはネットワーク接続を使用します。
- 外部のHTTP / HTTPSリンクは標準ブラウザーで開き、メールリンクはOSの既定アプリに渡します。
- ローカルファイルへのリンクは直接開きません。「ファイルを追加」から選択してください。
- Markdown中のHTML・スクリプトは実行しません。

## 保存するデータ

元のMarkdownは読み取り専用で、アプリからアップロードしません。1ファイルの上限は **20 MB** です。

| データ | 保存場所 |
| --- | --- |
| ファイル一覧（フルパス） | Electronの `userData` 内の `library.json` |
| テーマ・フォント・文字サイズ・選択ファイル | アプリのlocalStorage |

外部画像やリンクを開く場合は、リンク先への通信が発生します。

## 開発・テスト

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | ViteとElectronを開発モードで起動 |
| `npm run dev:web` | ブラウザーでUIを確認 |
| `npm run build` | フロントエンドを `dist/` にビルド |
| `npm start` | ビルド済みの画面をElectronで起動 |
| `npm test` | ファイル読み込み・Finder連携処理・Markdownレンダリングのテスト |
| `npm run test:electron` | ビルドしてElectronの画面操作テストを実行 |
| `npm run dist` | 実行環境向けのインストーラーを作成 |

Electronの画面操作テストには、GUIアプリの起動を許可する環境が必要です。Finder連携処理の単体テストは、Electronを模擬した環境でファイル受け渡しを確認します。

`npm run dev:web` はUI確認用です。ブラウザーではファイル一覧の再起動後の復元、フルパス取得、ローカル相対画像の表示が制限されます。通常はElectronで使用してください。
